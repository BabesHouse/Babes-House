# Babes House Website

A simple GitHub Pages starter site for babes-house.com.

## Files

- `index.html` - upcoming events / home page
- `about.html` - about page
- `contact.html` - contact page
- `style.css` - all visual styling

## Updating events

Open `index.html` and find the `events-grid` section. Copy an existing `.event-card`,
then change the date, event type, title, description, time, and ticket link.

Delete old event cards when events have passed.

## Important before publishing

1. Replace `hello@babes-house.com` in `contact.html` with the email address you actually want to use.
2. Replace the placeholder Instagram link (`href="#"`) with the real Instagram URL.
3. Replace the sample events with your actual events.
